# 视觉统一设计规格（青绿科技风）

**日期**：2026-06-23  
**状态**：已实现  
**项目**：arrow-fe  
**决策人**：设计方向由产品讨论确认，采用方案 A（青绿蛇 + 网格区分）

---

## 1. 设计决策摘要

在保留 **深海军蓝 + 青绿 accent 科技风** 的前提下，将蛇身从暖橙改为 **青绿渐变实线路径**，并通过 **线型/亮度/粗细** 与辅助虚线网格区分，避免辅助开启时可读性下降。

**不做：** 照搬参考图的暖棕粗蛇、木纹理、外边框棋盘。

---

## 2. 色板与职责

| 令牌 | 值 | 用途 |
|------|-----|------|
| `--game-bg` | `#070d16` | 全 app 背景 |
| `--game-accent` | `#4deeea` | UI 交互、提示环、成功粒子 |
| `--game-accent-2` | `#7ef29a` | 渐变终点、辅助强调 |
| `--game-danger` | `#ff4d6d` | 阻挡、失败、扣血 |
| `--game-warn` | `#ffb703` | 辅助按钮（开/关） |
| **蛇身主线** | `#3dd9d5 → #6ef0a0` | Pixi 实线，略粗，轻微 glow |
| **蛇头** | `#2ebfb8` | 比蛇身略深，眼睛深色 |
| **辅助网格** | `#8898aa` @ 28% | 虚线，细，无填充 |
| **辅助交点** | `#8898aa` @ 22% | 小圆点，比蛇身暗且小 |

**规则：** 青绿负责品牌与 UI；蛇身用实线渐变；辅助网格用 **灰蓝虚线**， deliberately 不用 accent 色，避免与蛇混淆。

---

## 3. 蛇身视觉（SnakeRenderer + SNAKE_THEME）

### 3.1 路径

- 保持「沿网格分割线交点连线」的现有几何模型，不改 game-core 逻辑。
- 线宽：`ROAD_WIDTH_RATIO` 从 `0.26` 提至约 `0.32`（高密度关卡更易辨认）。
- 主线：`road` / `roadLight` 改为青绿渐变（Pixi 可用两色 stroke 或分段近似；优先 `roadLight` 作 stroke，`road` 作 head 圆点）。
- 虚线装饰（蛇身中线 dash）：改为半透明白 `#fff8ee` @ 35%，宽度约为 road 的 12%。
- 可选：stroke 加 `alpha: 0.92` 与 1px 外 glow（同色 @ 15%），增强在深色底上的体积感。

### 3.2 蛇头

- 面部填充 `#2ebfb8`，略深于蛇身。
- 眼睛 `#1a2838`，箭头 `#ffffff`。
- **默认无 accent 环**；仅在 `activeHintSnakeId` 时显示 **暖白/黄色** 外环（`#ffe566` @ 90%），与青绿蛇身对比，不用青绿 hint 环（避免与蛇身同色）。

### 3.3 阻挡态

- `blockedFlash` 保持 `#ff4466`，动画闪红不变。

---

## 4. 辅助网格（与蛇身的区分策略）

| 属性 | 蛇身 | 辅助网格 |
|------|------|----------|
| 颜色 | 青绿渐变 | 灰蓝 `#8898aa` |
| 线型 | 实线 | 虚线 |
| 线宽 | 粗（~0.32 cell） | 细（~0.028 cell） |
| 透明度 | 高（~0.9+） | 低（~0.28） |
| 交点 | 无 | 小点 @ 0.22 |

辅助开启时：**蛇身为画面主角，网格为退后参考线**。用户关闭辅助后，网格消失，蛇身更清晰。

`assistGridLine` / `assistGridDot` 从当前浅灰改为上述灰蓝 token，写入 `SNAKE_THEME`。

---

## 5. 首页对齐（HomeView）

目标：首页预览 = 游戏棋盘的缩略版，消除割裂感。

### 5.1 mini-grid 预览

- 背景与游戏一致：深底 + 极淡内部网格线（可选）。
- 演示路径：改为 **青绿渐变折线**（与游戏蛇身同色），线宽加粗，圆角 join。
- 蛇头：小圆 + 眼睛，风格与 Pixi 蛇头简化一致（SVG）。
- 去掉纯青绿「箭头 polygon」演示，或保留为次级装饰；**主视觉必须是路径/蛇**。

### 5.2 四角按钮

- 保留现有布局与 icon。
- glow / border 统一走 `--game-accent`，gold/purple/green 角标 **降低饱和度 15–20%**，避免与主 accent 抢戏。

---

## 6. 游戏 HUD 微调（GameView）

- 布局不变（暂停 | 关卡 | 爱心；底栏提示/辅助）。
- 爱心：满 `#ff4d6d`，空 `#3a4558`（不用杂色）。
- 底部工具按钮：**仅 active 态** 强 glow（辅助「开」、提示触发后 2.5s 内）；默认态 pulse 动画减弱或去掉。
- 关卡 pill、暂停按钮：统一 `--game-glass` + accent border，不新增色相。

---

## 7. 棋盘舞台

- 保持 **无面板外边框**（已实现）。
- `drawStageDecor` 背景光晕：整体 alpha 再降 **25%**，减少与蛇身竞争。
- `drawBoardBackground`：保留轻微渐变面板；不再加 stroke 边框（已实现）。

## 9. 验收标准

1. 首页预览路径与游戏内蛇身 **色相/线型一致**，用户能识别为同一游戏。
2. 蛇身为青绿渐变实线，在 `#070d16` 上清晰可辨。
3. 辅助开启时，蛇身与虚线网格 **可一眼区分**（颜色 + 线型 + 粗细）。
4. 提示高亮为 **黄/白外环**，不与蛇身同色。
5. 阻挡/失败仍为红色系，不与品牌青绿混淆。
6. `npm run test` 全部通过（无逻辑变更，仅视觉）。
