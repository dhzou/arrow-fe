# 箭头消消乐（2D 平面版）设计规格

**日期**：2026-06-23  
**状态**：待审阅  
**项目**：arrow-fe

---

## 1. 项目概述

高度还原复刻热门「箭头消消乐」2D 平面版休闲益智游戏。采用 **Web 原型先行 → 微信小游戏/小程序移植** 的两阶段路线。

### 1.1 已确认需求

| 维度 | 决策 |
|------|------|
| 目标 | 高度还原复刻 |
| 平台 | Web 原型 → 微信小游戏/小程序 |
| 形态 | 2D 平面网格 |
| MVP 范围 | 核心玩法 + 基础 UX + 进度存档 + 每日挑战 + 提示/重置道具 |
| 技术栈 | Vue 3 + Canvas/PixiJS |
| 关卡 | 纯程序生成 |
| 进度 | 无限关卡，难度递增 |
| 失败机制 | 无硬性失败，偏休闲 |

## 2. 架构设计

### 2.1 推荐方案：逻辑与渲染分离

```
纯 TS 游戏内核 ←→ 渲染适配层 ←→ PixiJS (Web) / 微信 Canvas (后期)
       ↑
   Vue 3 UI 壳（菜单、HUD、弹窗）
```

**选型理由**：game-core 可独立单测；Web 阶段 PixiJS 开发效率高；移植小程序时仅替换渲染层。

**备选方案（未采用）**：
- 原生 Canvas 2D：包更小、移植成本低，但 Web 阶段开发慢
- 直接 uni-app：小程序路径短，但 Web 原型迭代体验差

### 2.2 分层结构

```
┌─────────────────────────────────────┐
│  Vue 3 应用层                        │
│  路由 / 首页 / 关卡页 / 每日挑战 / 设置 │
│  Pinia：用户进度、道具数量、设置       │
└──────────────┬──────────────────────┘
               │
┌──────────────▼──────────────────────┐
│  game-core（纯 TypeScript）           │
│  Grid / Arrow / MoveValidator         │
│  LevelGenerator / SolvabilityChecker  │
│  GameSession（状态机）                │
└──────────────┬──────────────────────┘
               │
┌──────────────▼──────────────────────┐
│  renderer 适配层                     │
│  Web: PixiJSRenderer                 │
│  后期: WxCanvasRenderer              │
└─────────────────────────────────────┘
```

### 2.3 页面结构

1. **首页** — 继续闯关、每日挑战、设置
2. **游戏页** — Canvas 棋盘 + 顶栏（关卡号、重置、提示）+ 底栏道具
3. **通关弹窗** — 下一关 / 重玩
4. **设置页** — 音效开关、进度重置

### 2.4 数据存储（Web 阶段）

- 全部使用 **localStorage**，无后端
- 存档字段：
  - `currentLevel: number`
  - `completedLevels: number[]`
  - `dailyChallenge: { date: string, seed: number, completed: boolean, bestMoves: number }`
  - `hintCount: number`（每关重置为 3）
  - `settings: { soundEnabled: boolean }`

## 3. 核心玩法

### 3.1 棋盘与箭头规则

- **网格**：二维整数坐标 `(x, y)`，每个格子最多一个箭头方块
- **方向**：四向 — 上 / 下 / 左 / 右（MVP 不支持斜向）
- **点击行为**：
  1. 取该格箭头方向 `d`
  2. 从当前格沿 `d` 逐步检测路径上是否有其他方块
  3. **有阻挡** → 播放「无法移动」反馈（轻微震动/音效），状态不变
  4. **无阻挡** → 该方块沿 `d` 飞出棋盘边界并消除
- **胜利条件**：棋盘上所有方块消除完毕
- **无解状态**：剩余方块均不可移动 → 引导用户使用「重置」，不设 Game Over

### 3.2 游戏会话状态机

```
idle → playing → (clearing 动画) → levelComplete
                 ↘ blocked反馈 → playing
playing → reset → playing（恢复初始快照）
playing → hint  → playing（高亮提示，消耗道具）
```

每关开始时，`GameSession` 保存一份 **初始快照**（deep clone），供重置使用。

### 3.3 休闲机制（无硬性失败）

- 不设步数/时间限制，顶栏只显示关卡号
- **每日挑战**：当天固定种子，完成后记录「最少步数」作自我挑战（本地），不做失败惩罚
- **提示**：高亮一个当前可消除的箭头，每关 3 次
- **重置**：恢复本关初始状态，不限次数

## 4. 程序生成

### 4.1 生成流程

```
LevelGenerator.generate(levelNumber, seed?)
  │
  ├─ 1. DifficultyProfile.fromLevel(levelNumber)  → 网格尺寸、目标方块数
  ├─ 2. ReverseBuilder.build(profile, seed)      → 逆向构造可解关卡
  ├─ 3. SolvabilityChecker.verify(level)          → 正向模拟二次校验
  └─ 4. 返回 LevelData { seed, grid, arrows, levelNumber }
```

### 4.2 逆向构造法（主生成策略）

1. 从空棋盘开始
2. 随机选一个「边界格 + 朝外方向」作为最后一步，反向插入方块
3. 重复直到达到目标方块数量
4. `SolvabilityChecker` 正向模拟验证：存在至少一条完整消除路径

生成的关卡 **100% 可解**，且天然有正确消除顺序，便于实现「提示」功能。若构造失败（网格已满等边界情况），降低目标方块数重试，最多 10 次。

### 4.3 难度曲线

| 关卡区间 | 网格大小 | 方块密度 | 备注 |
|---------|---------|---------|------|
| 1–10 | 4×4 ~ 5×5 | 60–70% | 教学期，几乎无干扰 |
| 11–30 | 5×5 ~ 7×7 | 70–80% | 开始出现多层遮挡 |
| 31–60 | 7×7 ~ 9×9 | 80–85% | 需要规划顺序 |
| 61+ | 9×9 ~ 12×12 | 85–90% | 上限封顶，避免屏幕过密 |

- 关卡号 `N` 只影响 `DifficultyProfile` 参数
- 同一 `(N, seed)` 永远生成相同关卡 → 存档可只存 `seed`，体积极小

### 4.4 每日挑战

- 种子：`hash(YYYY-MM-DD)` → 同一天相同布局
- 独立于主线进度，固定难度档（7×7 网格、75% 密度）
- 完成后记录：`completed: true`、`bestMoves: number`
- 次日自动刷新，不惩罚未完成

## 5. 道具

| 道具 | 行为 | MVP 数量 |
|-----|------|---------|
| **重置** | 恢复本关初始快照 | 无限次 |
| **提示** | 高亮一个当前可消除的箭头（3 秒闪烁） | 每关 3 次 |

提示实现：在 `game-core` 里维护「当前可移动箭头列表」，提示时取列表第一个并高亮。

## 6. UI 与视觉

### 6.1 风格

- **整体**：简洁扁平、浅色背景（米白/浅灰 `#F5F5F0`），棋盘区域居中
- **方块**：圆角矩形，柔和配色（蓝/绿/橙/紫区分方向或统一色 + 箭头图标）
- **箭头**：白色或深色粗箭头，方向一目了然
- **网格线**：浅灰细线
- **字体**：系统默认 sans-serif

### 6.2 布局

```
┌──────────────────────────────┐
│  ←  第 12 关          ⚙️    │  顶栏
├──────────────────────────────┤
│         Canvas 棋盘           │  PixiJS 渲染，等比缩放
├──────────────────────────────┤
│  [🔄 重置]      [💡 提示 x3] │  底栏道具
└──────────────────────────────┘
```

- **响应式**：Canvas 等比缩放，最大宽度 480px，移动端竖屏优先
- **MVP 不做**：皮肤系统、主题切换

### 6.3 页面流转

```
首页 ──→ 主线游戏页 ──→ 通关弹窗 ──→ 下一关
  │                              ↘ 重玩
  └──→ 每日挑战页（同游戏页，不同 seed 来源）
  └──→ 设置页
```

## 7. 动画与音效

### 7.1 动画（PixiJS 层）

| 事件 | 动画 |
|-----|------|
| 飞出 | 方块沿箭头方向匀速移出棋盘（~300ms），然后销毁 |
| 阻挡 | 方块轻微回弹 + 红色闪烁（~200ms） |
| 提示 | 目标方块黄色脉冲边框（3 秒） |
| 通关 | 简单缩放动画 → 弹窗 |

- 动画播放中锁定输入，防止快速连点重复触发

### 7.2 音效

| 事件 | 音效 |
|-----|------|
| 方块飞出 | 轻 pop |
| 阻挡 | 短 buzz |
| 通关 | 短 chime |
| 按钮点击 | 轻 tap |

- 设置页可开关，默认开启
- 使用 Web Audio API 或预加载 `.mp3`，总体积控制在 100KB 内

## 8. 错误与边界处理

| 场景 | 处理 |
|-----|------|
| localStorage 不可用 | 降级为内存存档，提示「进度无法保存」 |
| 生成关卡超时（>500ms） | 降低密度重试，最多 10 次 |
| Canvas 初始化失败 | 显示错误页 + 刷新按钮 |
| 用户快速连点 | 动画播放中锁定输入 |
