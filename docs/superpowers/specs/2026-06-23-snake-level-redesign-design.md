# 蛇形箭头谜题 · 关卡系统重设计规格

**日期**：2026-06-23  
**状态**：待审阅（v2 — 修正蛇数上限）  
**项目**：arrow-fe（Web 优先）

---

## 1. 背景与目标

当前 100 关全量 bake 方案存在以下问题：

| 问题 | 表现 |
|------|------|
| 内容重复 | 31–100 关多为 20–30 关旋转/镜像派生 |
| 扩展性差 | 全 JSON bake，无法真正「无限闯关」 |
| 前期缺乏设计 | 缺少教学节奏与主题造型关 |
| 视觉可读性 | 100 蛇时线条过密——靠**渲染紧凑**与**棋盘随蛇数扩展**解决，而非减少蛇数 |

### 1.1 已确认需求

| 维度 | 决策 |
|------|------|
| 布局（B） | **渲染紧凑**（细线 + 每蛇一三角）；格子 pitch 偏紧；棋盘随蛇数**放大**以保持可玩 |
| 内容（C） | 分阶段主题/造型关，减少纯随机感 |
| 进度 | **无限关卡**，`currentLevel` 无上限 |
| 固定关数量 | **1–30 关** JSON 预制 |
| **蛇数上限** | **100 条**（高关必须达到，与现网一致） |
| 主题关节奏 | 每 **10 关** 插入 1 个主题造型关（40、50、60…） |

> **重要澄清**：「紧凑」指**视觉呈现**（线型、间距、一蛇一箭头），**不是**把高关蛇数压到 35。高难度仍要 **100 条蛇**。

## 2. 关卡分区

```
┌─────────────────────────────────────────────────────────────┐
│ L1–10   教学区     固定 JSON · 3→12 蛇                      │
├─────────────────────────────────────────────────────────────┤
│ L11–30  主题章     固定 JSON · 造型关 · 12→40 蛇            │
├─────────────────────────────────────────────────────────────┤
│ L31+    无限区     运行时生成 · 40→100 蛇 · L50+ 稳定 100  │
│         每 10 的倍数关 → 主题模板变体（同样遵循蛇数曲线）      │
└─────────────────────────────────────────────────────────────┘
```

### 2.1 教学区（L1–10）

| 关 | 蛇数 | 棋盘约 | 设计要点 |
|----|------|--------|----------|
| 1 | 3 | 8×8 | 单步可清 |
| 2 | 4 | 9×9 | 阻挡演示 |
| 3–5 | 5–8 | 10×10 | 顺序依赖 |
| 6–8 | 8–10 | 11×11 | 拐角增多 |
| 9–10 | 10–12 | 12×12 | 综合小谜题 |

### 2.2 主题章（L11–30）

| 关段 | 主题示例 | 蛇数 |
|------|----------|------|
| L11–15 | 心形、箭头、十字 | 12→20 |
| L16–20 | 螺旋、框形、阶梯 | 20→28 |
| L21–25 | 对称图案、双环 | 28→35 |
| L26–30 | 章末 Boss 造型 | 35→**40** |

L30 故意低于 100，为 L31+ 无限区留出爬升空间。

### 2.3 无限区（L31+）

**生成策略**：

```typescript
function resolveSnakeLevel(n: number): SnakeLevelData {
  if (n <= 30) return loadCoreLevel(n)
  if (n % 10 === 0) return buildThemeVariant(n, pickTheme(n))
  return generateSnakeLevel(n, levelSeed(n)) // 使用统一难度曲线
}
```

**蛇数曲线（31+，目标 L50+ 达 100）**：

| 关卡段 | 蛇数 | 棋盘约（宽×高） | 说明 |
|--------|------|-----------------|------|
| 31–40 | 40→55 | 18×18 → 22×22 | 从主题章平滑接续 |
| 41–50 | 55→80 | 22×22 → 28×28 | 加速爬升 |
| 51–60 | 80→100 | 28×28 → 34×34 | 逼近封顶 |
| **61+** | **100** | **36×34 ~ 44×42** | 与现 `difficultyForLevel` 高关一致 |

**核心公式（31+，与现有生成器对齐并扩展）**：

```
t = levelNumber - 31
snakeCount = min(100, 40 + floor(t * 1.35) + floor(t / 25) * 3)
// L31=40, L40≈52, L50≈67→调参至80, L55+→100

// 沿用现有 sideFactor / area 约束（snake-generator.ts）：
// - MAX_SNAKES = 100
// - maxW 44, maxH 42（L20+ 档）
// - area / snakeCount ≥ 3
```

**紧凑约束（仅影响视觉与生成质量，不砍蛇数）**：

- 渲染：`cellPitch = cellSize × 0.84`（已实现）
- 蛇长：高关 `minLength 3`，`maxLength` 受面积约束，**长蛇比例 ≤ 15%**
- 生成失败：seed 偏移重试；必要时略扩棋盘，**不降 snakeCount 目标**

**主题关（L40、50、60…）**：

- 模板基础造型 + 按当前关 `snakeCount` **增补蛇**至曲线目标（`scaleHandcraftedLevel` 改进版）
- L50、L60… 主题关同样可达 100 蛇（L100 主题关 = 100 蛇 + 造型骨架）

## 3. 难度函数

**统一入口** `snakeDifficultyForLevel(levelNumber)`：

| 区间 | 来源 |
|------|------|
| L1–30 | bake 脚本逐关指定 profile |
| L31+ | 公式 + 现有 `generateSnakeLevel` / `difficultyForLevel` 逻辑，**MAX_SNAKES = 100** |

保留并微调现有常量：

```typescript
export const SNAKE_BASE_COUNT = 5
export const SNAKE_GROWTH_RATE = 1.2
export const PACK_MAX_SNAKES = 100  // 不变
```

无限区 L61+ 的 `snakeCount` 恒为 **100**。

```

  theme-levels.ts             # 新：模板加载、变体、按 snakeCount 扩蛇
```

## 5. API 变更

| 函数 | 行为 |
|------|------|
| `getSnakeLevelOrVariant(n)` | n≤30 读 core；n%10===0 主题；否则 generate |
| `maxBuiltInLevel()` | **30**（仅预制 JSON 数量，非游戏总关数） |
| `targetSnakeCount(n)` | 公开：L61+ 返回 100，供 UI/测试 |

进度 **无限**；UI 只显示「第 N 关」，不显示「/100 关总数」。
